# 🎓 Campus Market Hub

> A secure, digital marketplace tailored exclusively for university students and staff to buy, sell, exchange, donate, and advertise goods and services within a trusted campus environment.

---

## 🗄️ Database Schema & Entities

The database structure is normalized with foreign key constraints, composite performance indexes, and full-text search capability:

1. **`users`**:
   - Stores university students, faculty/staff, and administrators.
   - Enforces unique `Registration_StaffNo` and unique university `Email`.
   - Tracks `Role` (`Student`, `Staff`, `Admin`), `IsVerified` status, and `CampusDepartment`.
2. **`categories`**:
   - Seeded with core student categories: `Textbooks`, `Electronics`, `Furniture`, `Clothing`, `Learning Materials`, `Services`, `Free/Donations`.
3. **`products`**:
   - Tracks item name, description, category, seller, price (0.00 for donations/exchanges), condition (`Brand New`, `Like New`, `Good`, `Fair`), pickup spot, views, and `ListingType` (`Sell`, `Exchange`, `Donate`, `Service`).
4. **`messages`**:
   - Product-contextual direct messaging between buyers and sellers with unread receipt tracking.
5. **`transactions`**:
   - End-to-end lifecycle audit log tracking states (`Pending` -> `Completed` -> `Cancelled`), meeting locations, agreed prices, and completion timestamps.
6. **`recommendations`**:
   - Stores computed scores (`0.00` to `0.99`) and natural language match rationale generated by the recommendation engine.
7. **`user_activity_logs`**:
   - Audit trail of searches, product views, and category interactions that feed the machine learning algorithms.
8. **`complaints_reviews`**:
   - 1-to-5 star peer feedback ratings and fraud report tickets submitted to the admin desk.

## 🚀 Quick Setup Instructions (XAMPP / Local PHP & MySQL)

### Prerequisites
- **XAMPP**, **WampServer**, or native **PHP (8.0+)** and **MySQL (5.7+ / 8.0+)**
- Any modern web browser (Chrome, Edge, Firefox, Safari)
- *(Optional)* Node.js if you wish to run the standalone Socket.io WebSocket server.

### Step 1: Copy Project into XAMPP Web Root
Copy or clone this repository into your XAMPP `htdocs` directory:
- **macOS / Linux:** `/Applications/XAMPP/xamppfiles/htdocs/campus-market-hub`
- **Windows:** `C:\xampp\htdocs\campus-market-hub`

*(Alternatively, you can run directly from this directory using the PHP built-in server!)*

### Step 2: Create Database & Import Schema
1. Start **Apache** and **MySQL** in your XAMPP Control Panel.
2. Open **phpMyAdmin** (`http://localhost/phpmyadmin`).
3. Click on the **SQL** tab and run:
   ```sql
   CREATE DATABASE campus_market_hub CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
4. Click on the **Import** tab, browse to `database/schema.sql`, and click **Go** (or run `mysql -u root -p campus_market_hub < database/schema.sql` via terminal).
5. All tables, constraints, indexes, and realistic campus seed data will be populated automatically!

### Step 3: Configure Environment (`.env`)
1. In the project root, copy the environment template:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` and verify your MySQL credentials (default for XAMPP is user `root` with empty password):
   ```ini
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_NAME=campus_market_hub
   DB_USER=root
   DB_PASS=
   ```

### Step 4: Run the Application!
You have two easy ways to run the project:

#### Option A: Via PHP Built-in Server (Recommended & Fastest)
In your terminal, navigate to the project directory and run:
```bash
php -S localhost:8000 -t public
```
Now open **[http://localhost:8000](http://localhost:8000)** in your browser!

#### Option B: Via XAMPP Apache
If placed in `htdocs/campus-market-hub`, navigate to:
**`http://localhost/campus-market-hub/public/`**

## 🧠 Intelligent Recommendation Engine Details

The Recommendation Engine (`services/RecommendationEngine.php`) runs **100% locally in native PHP & MySQL** with zero external dependencies:

1. **Signal Weighting:**
   - Product View: `1.0`
   - Keyword Search: `2.0`
   - Message Inquiry: `3.0`
   - Completed Transaction: `5.0`
2. **Category Affinity Score:**
   - Computes decaying user affinity across all 7 campus categories.
3. **Content Matching:**
   - Scans user search keywords and tokens against listing titles, descriptions, and condition metadata.
4. **Trust & Safety Boost:**
   - Grants weight boosts (+0.05) to university-verified student/staff accounts.
5. **Periodic CLI Scoring:**
   - Can be triggered manually or scheduled in crontab:
     ```bash
     php scripts/cron_recommendations.php
     ```
   - Can also be recomputed on-demand via the user profile dashboard button.

## 🛡️ Campus Fraud & Safety Features

- **Institutional Email & ID Validation:** Prevents outside commercial spam by verifying campus email domains and registration numbers.
- **Peer Trust Ratings:** Star ratings (1-5) and transparent feedback left only after completed transactions.
- **Fraud Reporting Desk:** Users can flag suspicious listings or upfront payment requests directly to `/admin` for instant takedown and account suspension.
